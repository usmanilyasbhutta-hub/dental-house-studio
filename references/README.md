# references/ (gitignored)

Reference videos (own reels, liked reels from Instagram) and their analysis.
They may show patients or other clinics' work, so they are **never committed**.

- `inbox/`: drop videos here
- `python3 scripts/analyze_reference.py references/inbox/*` → `analysis/<name>/metrics.json`, `sheet.jpg`, `analysis/summary.md`
- Findings go into `docs/style-profile.md` (committed, text only).
