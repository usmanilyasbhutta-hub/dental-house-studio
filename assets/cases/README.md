# Patient consent forms (NOT in git)

Put each case's signed consent here: `assets/cases/<case_id>/consent.pdf`.
This folder is gitignored, and the render refuses a real case without it.
Photos go in `public/cases/<case_id>/` (also gitignored). Never put consent forms in `public/`.
Keep the originals in the clinic's records system. These copies are only for the compliance check.
